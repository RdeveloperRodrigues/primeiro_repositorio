# Como criar um repositorio no GitHub

E necessario ter instalado o git no computador, vamos instalar tambem o **GitiHbu no Desktop** para facilitar.

## Passo a passo
Supondo que voce ja tenha um projeto pronto criado, faça o seguinte:

-Abrir o CMD dentro da pasta e digitar o comando ```git init```
-Ir no GitHub Desktop e escolher a opção ```Add existing repositorio``` e selecionar a pasta do projeto
-por fim, fazer um comit e publicar. **atenção:** lembrar de deixar sempre publico
